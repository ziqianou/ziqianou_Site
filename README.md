# ziqianou 个人网站

这是 ziqianou 的个人主页，展示个人信息、技能和社交链接。

## 项目简介

这是一个纯静态的个人网站，使用 HTML、CSS 和 JavaScript 构建，具有动态星空背景效果和响应式设计。

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- GitHub Pages (部署)

## 项目结构

```
.
├── index.html          # 主页面
├── 404.html           # 404 错误页面
├── css/               # 样式文件目录
│   └── page.css       # 主样式表
├── js/                # JavaScript 文件目录
│   └── page.js        # 主脚本文件
├── images/            # 图片资源目录
│   ├── ziqianou.jpg   # 头像
│   └── travel.png     # 开往图标
├── favicon.ico        # 网站图标
├── robots.txt         # 搜索引擎爬虫配置
└── sitemap.xml        # 网站地图
```

## 功能特性

- ✨ 动态星空背景效果
- 📱 响应式设计
- 🎨 简洁现代的 UI 设计
- 🔗 社交链接集成
- 👥 友情链接展示

## 本地预览

你可以使用任何 HTTP 服务器来预览网站：

### 使用 Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

### 使用 Node.js
```bash
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 部署

本项目通过 GitHub Actions 自动部署到 GitHub Pages。每次推送到 `main` 分支时，网站会自动更新。
